# Package Graph

Консольная программа для анализа зависимостей Python-пакетов. Сейчас реализован первый этап: чтение и проверка настроек из TOML и их вывод на экран. Получение зависимостей и построение графа будут добавлены на следующих этапах.

## Настройки

Настройки хранятся в файле `config.toml` в корне проекта:

```toml
package = "requests"
repository = "https://pypi.org"
test_mode = false
print_tree = true
filter = ""
```

- `package` — обязательное имя анализируемого пакета.
- `repository` — обязательный URL с `http` или `https`; в тестовом режиме — путь к существующему файлу.
- `test_mode` — режим тестового репозитория. По умолчанию `false`.
- `print_tree` — вывод дерева зависимостей на следующих этапах. По умолчанию `false`.
- `filter` — подстрока для исключения пакетов на следующих этапах. Пустая строка по умолчанию означает отсутствие фильтра.

Пути к файлам задаются относительно папки, из которой запущена программа. При неверном типе значения, неизвестном параметре или ошибке в обязательных настройках программа выводит сообщение об ошибке.

## Сборка и запуск

Требуется Go версии, указанной в `go.mod`. Команды выполняются из корня проекта:

```bash
make build     # сборка в bin/package-graph
make run       # запуск через go run
make test      # запуск тестов
```

Запуск собранной программы:

```bash
./bin/package-graph
```

Для приведённого примера программа выведет:

```text
package = requests
repository = https://pypi.org
test_mode = false
print_tree = true
filter =
```

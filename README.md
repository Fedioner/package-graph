# Этап 2. Получение прямых зависимостей

Программа получает метаданные Python-пакета из JSON API PyPI и выводит строки его прямых зависимостей из поля `info.requires_dist`. Менеджер пакетов и сторонние библиотеки для получения зависимостей не используются.

## Настройки

В `config.toml` в корне проекта укажите имя пакета и адрес репозитория PyPI:

```toml
package = "requests"
repository = "https://pypi.org"
test_mode = false
print_tree = false
filter = ""
```

- `package` — имя анализируемого пакета.
- `repository` — базовый URL репозитория, который поддерживает JSON API PyPI.
- `test_mode` — режим тестового репозитория; на этом этапе используйте `false`.
- `print_tree` и `filter` предусмотрены для следующих этапов и пока не влияют на вывод.

Программа составляет адрес вида `https://pypi.org/pypi/requests/json`. Для каждого пакета запрашиваются только его прямые зависимости. Ограничения версий и условия выводятся в исходном виде; подбор версий и построение транзитивного графа пока не выполняются.

## Сборка, запуск и тесты

Требуется Go версии, указанной в `go.mod`. Команды выполняются из корня проекта:

```bash
make build
make run
make test
```

После сборки программу также можно запустить командой `./bin/package-graph`. При запуске нужен доступ к выбранному репозиторию. Текущие тесты проверяют конфигурацию; тесты получения зависимостей ещё не добавлены.

Пример фрагмента вывода для `requests` (содержимое зависит от метаданных PyPI):

```text
urllib3<3,>=1.26
certifi>=2023.5.7
```

Если поле `requires_dist` отсутствует или равно `null`, список будет пустым. Запрос ограничен тайм-аутом в 10 секунд.

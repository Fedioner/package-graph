# Этап 3. Построение графа зависимостей

Программа строит граф прямых и транзитивных зависимостей Python-пакета. Обход выполняется алгоритмом BFS без рекурсии; зависимости пакетов одного уровня загружаются параллельно, не более пяти запросов одновременно. Повторно встретившиеся пакеты не запрашиваются, связи и циклы сохраняются.

## Настройки

Программа читает файл `config.toml` из текущей рабочей папки:

```toml
package = "requests"
repository = "https://pypi.org"
test_mode = false
print_tree = false
include_extra = false
filter = ""
```

- `package` — исходный пакет.
- `repository` — базовый URL PyPI или путь к тестовому файлу.
- `test_mode` — использовать тестовый файл вместо PyPI; по умолчанию `false`.
- `print_tree` — настройка для этапа визуализации; пока не влияет на вывод.
- `include_extra` — включать зависимости с маркером `extra`; по умолчанию `false`.
- `filter` — подстрока для исключения пакетов; пустая строка отключает фильтр.

В PyPI-режиме имена пакетов нормализуются: буквы приводятся к нижнему регистру, последовательности `-`, `_` и `.` заменяются на `-`. В тестовом режиме используются имена из заглавных латинских букв. Фильтр чувствителен к регистру и применяется к этим именам; если он совпадает с исходным пакетом, граф не строится.

Ограничения версий и условия сохраняются в выводе. Версии не подбираются, условия окружения не вычисляются. При `include_extra = false` любая запись, содержащая переменную `extra` в условии, исключается целиком. Поэтому граф может отличаться от результата установки через `pip`.

## Тестовый репозиторий

Укажите файл вместо URL:

```toml
package = "A"
repository = "test_repository.txt"
test_mode = true
include_extra = false
filter = ""
```

Файл содержит по одному пакету на строке: имя, двоеточие и зависимости через пробел. Допустимы только заглавные латинские буквы. Каждый пакет объявляется один раз, в том числе пакеты без зависимостей; все упомянутые зависимости должны быть объявлены. Пустые строки и комментарии запрещены.

Например, общий пакет `D` и цикл `D → A`:

```text
A: B C
B: D
C: D
D: A
```

При `package = "A"` и пустом фильтре программа выводит связи `A → B`, `A → C`, `B → D`, `C → D`, `D → A`; порядок строк может меняться. Если задать `filter = "B"`, связь с `B` исчезнет, а `D` останется доступным через `C`.

Для проверки цепочки можно заменить содержимое файла на:

```text
A: B
B: C
C:
```

Ожидаемые связи: `A → B` и `B → C`. Если исходный пакет не имеет зависимостей, текущая версия не выводит строки графа.

## Сборка и запуск

Нужен Go версии, указанной в `go.mod`. Из корня проекта:

```bash
make build
make run
make test
```

`make test` запускает существующие проверки конфигурации. Для работы с PyPI необходимо сетевое соединение; тайм-аут одного запроса составляет 10 секунд. Ошибки отдельных пакетов сохраняются в графе и выводятся рядом со связями.
